# 出師表 — 아침 상소 창

매일 **오전 7시**와 **컴퓨터에 로그인할 때마다** 제갈량 말투의 조언 창을 띄웁니다.

- 제1표: 클로드 코드 초보자용 병법 (공백 포함 약 2,200자)
- 제2표: 사업과 삶의 방향 (공백 포함 약 3,100자)
- 날마다 바뀌는 「今日一言」 한 줄
- 가로쓰기(기본) / 세로쓰기(옛 상소문 방식) 전환 버튼

## 설치

이 `chulsapyo` 폴더를 통째로 내려받은 뒤:

**Windows** — `install-windows.cmd` 더블클릭 (관리자 권한 불필요)
- 파일을 `%LOCALAPPDATA%\Chulsapyo`로 복사
- 작업 스케줄러에 `Chulsapyo-Morning` (매일 07:00) 등록
- 시작프로그램 폴더에 바로가기 추가 (로그인 시)
- Edge가 있으면 주소창 없는 앱 창으로, 없으면 기본 브라우저로 엽니다.
- 제거: `uninstall-windows.cmd`

**macOS** — 터미널에서 `bash install-mac.sh`
- 제거: `bash uninstall-mac.sh`

> 오전 7시에 컴퓨터가 꺼져 있으면 그 시각 알림은 건너뛰고, 켜서 로그인할 때 뜹니다.
> 7시 직전에 켜면 두 번 뜰 수 있습니다.

## 글 바꾸기

본문은 전부 `content.js`에 있습니다. 고친 뒤 설치 스크립트를 다시 실행하면 반영됩니다
(또는 설치 폴더의 `content.js`를 직접 고쳐도 됩니다).

지난 대화를 기억하는 claude.ai 채팅에서 아래 문장을 붙여 넣으면 더 개인화된 본문을 받을 수 있습니다:

> 지금까지 나와 나눈 대화에서 알게 된 내 사업, 목표, 고민을 바탕으로, 제갈량 출사표 말투로
> ① 클로드 코드 초보자 조언 2,000자 ② 사업과 삶의 방향 조언 3,000자를 써 줘.
> 확인된 사실과 추정은 구분해 줘. 문단은 빈 줄로 나누고, 항목은 "一." "二." 처럼 시작해 줘.

받은 글을 `content.js`의 `part1.body`, `part2.body` 백틱(\`) 사이에 붙여 넣으면 됩니다.
