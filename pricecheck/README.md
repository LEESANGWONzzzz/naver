# pricecheck — 품번으로 KREAM / POIZON 시세 조회

아울렛에서 품번을 확인하면 집 PC가 크림과 포이즌을 조회하고, 매입가를 넣으면 스마트스토어 순수익까지 계산한다.
아이폰에서는 Remote Control로 명령한다.

> 2026-09-26 실제 페이지(DD1391-100) 글자 구조에 맞춰 가격 읽는 규칙(`parsers.py`)을 만들었다.
> 사이트 화면이 바뀌면 `debug` 폴더 파일을 Claude에게 보여주고 `parsers.py`를 고친다.

## 1단계: PC 설치 (Windows, 한 번만)

1. **Python 설치**: https://www.python.org/downloads/ 에서 설치. 설치 첫 화면에서 **Add python.exe to PATH** 체크.
2. **이 저장소 받기**: GitHub에서 Code → Download ZIP으로 받아 압축을 푼다 (예: `C:\work\naver`).
3. **명령 프롬프트(cmd)** 를 열고:

```
cd C:\work\naver\pricecheck
pip install -r requirements.txt
```

브라우저는 윈도우에 기본으로 깔린 Edge를 쓴다. 별도 브라우저 설치는 필요 없을 것으로 보지만, 실행 시 브라우저 관련 오류가 나면 아래를 한 번 실행:

```
python -m playwright install msedge
```

## 업데이트 (Claude가 코드를 고친 뒤)

`pricecheck` 폴더에서 `update.cmd` 실행. 파일마다 `updated: 파일이름`이 나오면 끝.
(raw.githubusercontent.com 주소는 몇 분간 예전 파일을 줄 수 있어서, 캐시 없는 GitHub API 주소로 받는다.
저장소를 비공개로 바꾸면 이 방법은 안 되고 브라우저로 ZIP을 받아야 한다.)

## 주력 사용법: 품번 + 매입가 -> 사입 판정 + 추천 사이즈

```
run.cmd DD1391-100 69000
run.cmd DD1391-100 69000 --sizes 250-290
run.cmd DD1391-100 69000 --min-profit 15000
run.cmd DD1391-100 69000 --kream-only
```

하는 일:
1. 크림에서 모델번호가 맞는 상품을 찾고, 사이즈마다(기본 230~300, 5 단위) `?size=` 페이지를 열어
   **구매가**와 **최근 체결 5건(날짜)** 을 모은다.
2. 사이즈별 **크림 예상가** = 구매가와 최근 체결가 중 낮은 값 (보수적으로)
3. **판매 속도** = 최근 체결 5건이 며칠 사이였는지 (3일 이내 매우 빠름, 7일 빠름, 21일 보통, 그 이상 느림)
4. 크림 판매 수수료, 택배비를 빼고 순수익 계산
5. 순수익이 기준(기본 10,000원) 이상이고 속도가 보통 이상인 사이즈를 (순수익 x 속도) 순으로 최대 3개 추천
6. 포이즌 소비자 사이트 사이즈별 가격과 셀러센터 30일 판매량은 **참고로 표시** (판정에는 안 씀)
   - 포이즌 가격이 실제 정산가와 같다고 확인되면 `--use-poizon-price`로 판정에 포함

결과는 화면, `results\last_report.txt`, `results\scan_log.csv`(사이즈별 한 줄)에 남는다.
조회 시간은 1~2분 (사이즈 15개 기준). 사이즈 범위를 좁히면 빨라진다.

## 사이즈 하나만 자세히 보기

```
run.cmd DD1391-100
run.cmd DD1391-100 --size 270
run.cmd DD1391-100 --size 270 --buy 69000
run.cmd DD1391-100 --size 270 --buy 69000 --kream-level 2
run.cmd DD1391-100 --only kream
run.cmd DD1391-100 --poizon-public
run.cmd --login
```

- `--login`: 처음 한 번 실행. 창에 탭 두 개가 열리면 크림, 포이즌 셀러센터에 각각 로그인한 뒤 cmd에서 Enter.
- `--kream-level`: 크림 판매자 등급 (1~5, 기본 1 = 수수료 6%). 등급은 크림 앱에서 확인.
- POIZON은 기본으로 **판매자 센터**(seller.poizon.com/main/dataBoard)를 연다.
  상단 검색창에 품번을 넣고 "검색 및 입찰"을 눌러, 결과 표에서 **최근 30일 평균 거래가, 중국 구매자 페이지 노출가,
  최근 30일 판매량, 현지 판매자 30일 판매량**을 읽는다 (전체 사이즈 기준, 사이즈별은 아직 미지원).
  "입찰 등록" 버튼은 절대 누르지 않는다.
- `--poizon-public`: 예전처럼 소비자 사이트(kr.poizon.com) 사이즈별 가격 조회.

- Edge 창이 잠깐 떴다가 닫힌다. 로그인이 필요하다고 나오면 그 창에서 한 번 로그인하면 다음부터 유지된다 (`browser_profile` 폴더에 저장).
- 결과는 화면에 나오고 `results\price_log_v2.csv`에도 누적된다 (엑셀로 열림).
- 매번 `debug` 폴더에 화면 캡처(png)와 페이지 글자(txt)가 저장된다.
  **처음 몇 번은 결과와 이 파일들을 Claude에게 보여줘야 정확하게 고칠 수 있다.**

출력 예시 (2026-09-26 DD1391-100 실제 페이지로 시험한 결과, 매입가 69,000 가정):

```
[KREAM]
  상품: 나이키 덩크 로우 레트로 블랙
  모델번호 일치: 예
  발매가: 139,000원
  상단 구매가(...): 85,000원  (스마트스토어 85,000원 판매 시 순수익 10,566원)
  270 최근 체결: 91,000원 (6시간 전)  (스마트스토어 91,000원 판매 시 순수익 16,169원)
  최근 체결 거래: 295 107,000원(1시간 전), 270 91,000원(6시간 전), ...

[POIZON]
  상품: 나이키 덩크 로우 레트로 블랙
  크림 상품명과 일치: 예
  270: 123,200원  (스마트스토어 123,200원 판매 시 순수익 46,234원)
  전체 사이즈 최저: 270 123,200원
```

- **모델번호 일치: 아니오**가 나오면 크림 검색 첫 번째 상품이 다른 상품일 수 있으니 주소를 눌러 직접 확인.
- 포이즌 페이지에는 모델번호가 없어서, 크림 상품명과 같은지로 대신 확인한다.
- 크림은 같은 이름의 다른 상품(예: DD1391-100 / HF5441-100)이 있어서, 검색 상위 5개를 차례로 열어 모델번호가 맞는 상품을 고른다.
- `--size`를 넣으면 크림 상단에 "270 구매가"처럼 그 사이즈 구매가가 나온다 (2026-09-26 확인).
- 순수익은 채널별로 보여준다. 수수료 설정은 `fees.py`.
  - 크림 판매 시 (레벨1): 판매가 − (판매가 × 6% + 2,500) × 1.1 − 택배 2,500 − 매입가. 수수료 최대 300,000원 (2026-03-02 적용 기준)
  - 포이즌 판매 시: 150,000원 이하 = 수수료 15,000 + 택배 2,500 / 150,000원 초과 = 판매가의 10%
  - 스마트스토어 판매 시: `profit.py` 공식

## 3단계: 아이폰에서 명령하기 (Remote Control)

1. **Git for Windows 설치**: https://git-scm.com/download/win (Claude Code가 윈도우에서 사용)
2. **Claude Code 설치**: PowerShell을 열고

```
irm https://claude.ai/install.ps1 | iex
```

3. cmd에서 저장소 폴더로 가서 로그인 후 Remote Control 켜기:

```
cd C:\work\naver
claude
```

처음 한 번 로그인하고 `/exit`로 나온 뒤:

```
claude remote-control
```

4. 아이폰 Claude 앱 → Code 쪽에 이 PC 세션이 보이면 거기서
   "DD1391-100 270 시세, 매입가 69000" 처럼 보내면 된다.

주의:
- 외출 중 PC가 **절전 모드로 들어가지 않게** 설정 (설정 → 시스템 → 전원 → 화면과 절전 → 절전 모드 "안 함").
- Remote Control을 쓸 수 있는 요금제인지, 정확한 메뉴 위치는 공식 문서에서 확인:
  https://code.claude.com/docs
- 설치 명령어가 바뀌었을 수 있으니 안 되면 위 문서의 Windows 설치 안내를 따른다.

## 이용약관

크림, 포이즌이 자동 조회를 허용하는지는 확인하지 못했다.
개인 사입 판단용으로 필요할 때 한 건씩 조회하는 용도로만 쓰고, 대량 반복 조회는 하지 않는다.
